# FlyForge

Original research-program repo. The experiment engine is **[kvnloo/evolution-lab](https://github.com/kvnloo/evolution-lab)**. This tree is not a FlyGym, OpenEvolve, Stonkfly, or fly-wirehead fork.

Goal (from the engine):

> Continuously discover, verify, and explain computational systems that expand the achievable frontier between capability and resources.
